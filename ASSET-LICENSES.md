# Locally hosted assets

Google Fonts families Josefin Sans, Lora and Open Sans are self-hosted with their SIL Open Font License files under `fonts/`. CSS preserves the requested font faces.

Font Awesome 4.3.0 by Dave Gandy uses SIL OFL 1.1 for fonts and MIT for code; its original project/license information is retained in `fonts/FontAwesome-LICENSE.txt`. The original font names and files are preserved.

jQuery 2.1.3 is under the MIT license; Bootstrap 3.3.6 is under the MIT license. Their copyright/license headers remain in the vendored JavaScript. These are local copies of the versions used by the existing theme.

No remote font or JavaScript CDN is needed to read this site. The optional LightWidget gallery loads only after the visitor selects its consent button.
